# 中文编程语言 · 函数命名规范（v1.0 · 2026-08-28）

> 来源：T9-2b 压力测试实证（调用缺陷四例报告）——运算词与中文数字
> 组合的函数名会被词法器拆分，导致调用解析失败。本规范为**强制约束**，
> 任务设计与教程示例同步遵守。

## 命名规则

1. **函数名必须以非运算词的中文字符开头**（如「递归」「倍增」「累计」），
   不得以 加/减/乘/除 开头。
2. **函数名内不得包含紧跟数字的运算词**（如「加一」「减二」——词法器
   会把「加一」拆为运算词「加」+ 数字「一」，调用时无法解析）。
3. **推荐形态**：双字以上中文词（递归汉诺/累计/倍增/筛选），或
   「动词短语」式命名（求和取整）。

## 合法/非法对照

| 函数名 | 合法性 | 说明 |
|---|---|---|
| 递归汉诺 | ✓ | 非运算词开头 |
| 累计 | ✓ | 非运算词开头 |
| 加一 | ✗ | 「加」为运算词 +「一」为数字，词法拆分 |
| 减二 | ✗ | 同上 |
| 乘法计算 | ✓ | 「乘法」整体非运算词 token |

## 实证

- 反例：`定义 加一（甲）：返回 甲 加 1；中间 = 加一（倍（3））…`
  → `加一（中间）` 编译为字符串常量（字节码
  `PUSH_CONST '加一（中间）'`），结果变量被赋值为字面文本。
- 正例：`定义 倍（甲）：返回 甲 加 甲；中间 = 倍（3）；结果 = 中间；止。`
  → `CALL (4, ['甲'])` 正确调用，结果 = 6.0。

## 参数命名

参数名建议使用单字代数符号（n/甲/乙）或非运算词中文词，避免与
运算词同名的参数（如名为「加」的参数）。
